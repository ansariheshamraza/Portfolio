# Hesham Raza Portfolio

A clean, modern portfolio showcasing my work as a builder, developer, and founder. Built with vanilla HTML, CSS, and JavaScript.

## What's Inside

- **index.html** — Main landing page with hero section, about, skills, featured projects, and contact
- **projects.html** — Full project showcase
- **certificates.html** — Certifications and achievements
- **pages/** — Individual project deep-dives (RachnaX, Kisaan App, SHAHVAR Store)
- **css/** — Modular stylesheets (reset, variables, components, layout)
- **js/** — Vanilla JavaScript for interactions and animations

## Design & Tech

- **Fonts:** Cormorant Garamond, DM Sans, Syne
- **Styling:** Custom CSS with CSS variables for theming
- **Interactions:** Smooth scrolling, fade-in animations, responsive navigation
- **No frameworks** — Just clean HTML, CSS, and vanilla JS

## Getting Started

1. Open `index.html` in your browser
2. Navigate through sections or use the menu
3. Check out individual projects for detailed case studies

## Features

- Fully responsive design
- Dark mode ready (CSS variables)
- Smooth scroll animations
- Mobile-friendly navigation toggle
- Social links and contact section
